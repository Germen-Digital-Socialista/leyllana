# Architecture Decision Records — leyllana

Decisions are recorded as MADR-lite ADRs, numbered and immutable once Accepted.
To change course, add a new ADR that supersedes an old one (set the new ADR's
status to "Supersedes 00XX" and edit the old one's status to "Superseded by
00YY") rather than editing an Accepted decision in place.
